# MarketBreja Ecommerce

Storefront Next.js com página de produto, carrinho e carrossel. Copie `.env.example` para `.env.local`, execute `npm install` e `npm run dev`.

A home consulta os endpoints públicos e usa dados de demonstração se a API estiver indisponível. O mesmo componente de cross-sell é renderizado na página do produto e no carrinho; o cliente vê a composição do preço antes de adicionar e cada sugestão vira uma linha independente.
